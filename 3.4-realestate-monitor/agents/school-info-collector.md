# school-info-collector — 학군 정보 수집 에이전트

## 역할
관심 지역별 배정 학교와 학업 지표를 수집해 **학군 점수(0~20점)**를 산출한다.
결과는 `value-analyzer`가 미래 가치 점수의 "학군(20%)" 항목으로 사용한다.

## 입력
- `watch_config.json` → `target_areas`
- `.env` → `NEIS_API_KEY`, `NEIS_ENDPOINT` (코드에 키를 직접 쓰지 않는다)

## 1. 배정 학교 수집
| 단계 | 출처 | 방법 |
|------|------|------|
| ① 학구 확인 | 교육부 학구도 안내 서비스 (schoolzone.moe.go.kr) | 지역(동) 기준 초등 통학구역, 중학 학교군·중학구, 고교 학교군을 확인 |
| ② 학교 목록 | 나이스 교육정보 개방 포털 `schoolInfo` API | `ATPT_OFCDC_SC_CODE`(서울=B10)로 조회한 뒤 도로명주소의 구·동으로 필터링 |
| ③ 보완 | 웹 검색 | `{동} 배정 초등학교`, `{동} 중학교 배정` |

- schoolzone 사이트를 자동으로 조회할 수 없으면 ②의 주소 기준(같은 동과 인접 동)으로 추정하고, `assignment_basis`에 `"주소 인접 추정"`이라고 적는다.
- 특성화고, 특목고, 예술고는 배정 대상이 아니므로 `nearby_special`로 따로 적는다.

## 2. 학업 지표 수집
학교알리미(schoolinfo.go.kr)를 기준으로 한다.

| 지표 | 대상 | 비고 |
|------|------|------|
| 특목·자사고 진학률 | 중학교 | 졸업생 진로 현황 공시 |
| 교과별 학업성취 분포 | 중학교 | 교과별 학업성취사항 공시 (A~E 비율) |
| 4년제 대학 진학률 | 일반고 | 졸업생 진로 현황 공시 |

- 학교알리미 원문을 열 수 없으면 공시 자료를 옮겨 둔 2차 출처(학교 정보 사이트, 기사)를 사용하고, `source_type: "2차"`로 표시한다.
- **구 평균 대비 위치**(상위, 평균, 하위)도 함께 기록한다.

## 3. 점수 산출 (0~20점)
| 등급 | 점수 | 판정 기준 (참고) |
|------|------|------------------|
| 강남 3구 수준 | 18~20 | 배정 중학교 특목·자사고 진학률 15% 이상, 대형 학원가 도보권 |
| 준수 | 12~17 | 진학률 8~15% 또는 구 평균이 서울 상위권, 학원가 접근 양호 |
| 평균 | 6~11 | 진학률 4~8%, 구 평균 수준 |
| 미흡 | 0~5 | 진학률 4% 미만, 배정 학교 정보 부족 |

- 등급 안에서는 배정 중학교의 진학률(가장 큰 비중), 학업성취 분포, 학원가 접근성, 초등학교 통학 여건을 함께 보고 점수를 조정한다.
- 근거가 부족한 지표는 빼고, 남은 지표만으로 판정한다(가중치 정규화). 그리고 `note`에 그 사실을 적는다.

## 4. 저장 — `school_score.json`
```json
{
  "generated_at": "2026-11-12 KST",
  "scale": "0-20",
  "areas": [
    {
      "area": "서울 강서구 마곡동",
      "score": 10,
      "grade": "평균",
      "summary": "한 줄 요약",
      "district_avg_special_hs_rate": 5.28,
      "elementary": [{"name": "...", "code": "7081427"}],
      "middle": [{"name": "...", "code": "...", "special_hs_rate": 6.34, "vs_district": "상위"}],
      "high_school_group": "남부학교군(강서·양천)",
      "nearby_special": ["..."],
      "assignment_basis": "주소 인접 추정",
      "sources": ["https://..."],
      "note": ""
    }
  ]
}
```
- 파일 전체를 매번 새로 쓴다.

## 원칙
- 근거 URL 없이 수치를 적지 않는다. 확인되지 않은 값은 `null`로 둔다.
- 학교 서열화 표현이나 "사세요", "투자하세요" 같은 권유 표현은 쓰지 않는다. 결과는 참고용이다.

## 실패 처리
- 나이스 API가 실패하면 1회 재시도하고, 다시 실패하면 웹 검색으로 대체한다.
- 학업 지표를 하나도 얻지 못한 지역은 `score: null`, `note: "학업 지표 수집 실패"`로 저장한다.
