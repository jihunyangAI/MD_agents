# price-chart — 가격 추이 시각화 에이전트

## 역할
`prices.csv`를 읽어 브라우저에서 바로 열리는 `price_chart.html` 한 파일을 만든다.
가격 조회·기록·알림은 하지 않는다.

## 실행
```
python price_chart.py
```
- 파이썬 표준 라이브러리만 사용하고, 결과 HTML도 외부 라이브러리·CDN 없이 **순수 HTML + CSS + JS(SVG)** 로 그린다.
- 데이터는 HTML 안에 JSON으로 포함되어 인터넷 없이도 열린다.

## 입력 — `prices.csv`
`수집일시, 상품ID, 상품명, 수집가격(원), 목표가격(원), 목표달성여부, 할인정보, 재고상태, 전일대비변동(원)`

## 출력 — `price_chart.html`
### 1. 현재 상태 요약 카드 (상품별)
| 항목 | 계산 |
|------|------|
| 현재가 | 가장 최근 수집가격 |
| 목표가 | 목표가격 |
| 달성율(%) | 목표가 ÷ 현재가 × 100, 현재가 ≤ 목표가이면 100% |
| 역대 최저가 | 전체 이력 중 최저 수집가격 |
| 배지 | 현재가 ≤ 목표가 → `달성`(초록 ✓), 아니면 `추적 중` |

### 2. 상품별 가격 변동 선 그래프
- 상품마다 차트 1개(가격대가 달라 한 축에 겹치지 않음), x축 = 수집 날짜, y축 = 가격(원)
- 상품마다 다른 색상의 선(색상 순서 고정: 파랑 → 주황 → 청록 → 노랑 …)
- **목표가**: 빨간 점선
- **역대 최저가**: 별(★) 마크 + "최저 N원" 라벨
- 마우스를 올리면 세로 보조선과 툴팁(수집일시, 가격, 목표가 대비)
- 수집이 1건뿐이면 점으로 표시하고 안내 문구를 붙인다.

### 3. 최근 가격 변동 내역 테이블
- `prices.csv` 최신 10건(수집일시 내림차순)
- 컬럼: 수집일시, 상품명, 수집가격, 전일대비(▲ 상승 / ▼ 하락), 목표달성, 할인정보, 재고

### 화면
- 다크 모드 자동 대응, 모바일 폭에서도 가로 스크롤 없이 카드·차트가 세로로 쌓인다.

## 완료 보고
```
생성: price_chart.html (상품 N개, 누적 M건)
- prd-001 …: 현재 / 목표 / 달성율 / 최저 / 상태
```
