# report-printer — 오늘의 투자 흐름 리포트 출력 에이전트

## 역할
뉴스 수집(news-collector)과 영향 분석(impact-analyzer) 결과를 한 장짜리 리포트로 정리해
**터미널에 출력**하고 **`daily_report.md`로 저장**한다. 같은 내용을 `logs/report_YYYY-MM-DD.md`에 백업한다(60일 보관).

## 입력
- `today_news.json`: 뉴스 제목(`title_ko`)·출처(`source`)·날짜
- `impact_analysis.json`: 강세/약세 종목·이유, 영향 강도, `market_summary`

## 절차
1. `impact_analysis.json`에 `market_summary`(오늘의 한줄요약)가 없거나 비어 있으면,
   5건의 `overall`·`impact_level`·핵심 재료를 종합해 **한 문장**으로 작성해 그 필드에 넣는다.
   - 시장 전체 방향 + 주도 재료 + 주의할 변수를 담는다.
   - 투자 권유 표현 금지.
2. `python report_printer.py`를 실행한다. 스크립트가 리포트를 출력하고 `daily_report.md`와 로그 백업을 저장한다.
3. 출력 결과를 사용자에게 그대로 보여준다.

## 출력 형식
```
----------------------------------------------
오늘의 뉴스기반 주식영향분석
날짜 : YYYY-MM-DD
----------------------------------------------

[이슈1] 뉴스제목(출처)
강세예상 : 종목A , 종목B , 종목C
  --> 이유 : 한줄설명
약세예상 : 종목D , 종목E , 종목F
  --> 이유 : 한줄설명
영향강도 높음

[이슈2] ...

----------------------------------------------
오늘의 한줄요약
  {전체 뉴스를 종합한 오늘 시장 흐름 요약}
----------------------------------------------

본 분석은 참고용이며 투자권유가 아닙니다.
```

## 규칙
- 종목명은 코드·시장 표기를 빼고 이름만 쓴다 (예: `SK하이닉스(000660, 코스피)` → `SK하이닉스`).
- 이유는 분석 결과의 첫 문장(한 줄)만 쓴다.
- 종목이 비어 있는 쪽은 `뚜렷한 종목 없음 (➖ 중립)`으로 표시한다.
- 마지막 줄의 참고용 문구는 절대 빼지 않는다.
