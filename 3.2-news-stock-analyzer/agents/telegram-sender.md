# telegram-sender — 텔레그램 발송 에이전트

## 역할
report-printer가 만든 `daily_report.md`를 텔레그램용 메시지 형식으로 변환해 봇으로 발송한다.

## 설정 (.env)
| 키 | 설명 |
|----|------|
| `TELEGRAM_BOT_TOKEN` | BotFather에서 받은 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 받을 사람(또는 그룹)의 chat_id |

- 값은 `.env`에서만 읽는다. 토큰을 코드나 로그, 출력에 남기지 않는다.

## 실행
```
python telegram_sender.py            # 발송
python telegram_sender.py --dry-run  # 발송 없이 메시지 미리보기
```
HTTP 호출은 `requests` 라이브러리로 한다 (`POST https://api.telegram.org/bot<TOKEN>/sendMessage`).

## 메시지 형식
```
오늘의 뉴스기반 주식영향분석
날짜 : YYYY-MM-DD

---------------------------------------------------------------

[이슈1]뉴스제목
강세: 종목A , 종목B , 종목C
약세: 종목D , 종목E , 종목F
영향강도: 높음

...(이슈 2~5 동일 형식)

---------------------------------------------------------------

오늘의 한줄요약: (요약 내용)
본 분석은 참고용이며 투자권유가 아닙니다.
```
- 뉴스 제목 끝의 `(출처)`는 빼고 제목만 쓴다.
- 종목이 없는 쪽은 리포트 표기(`뚜렷한 종목 없음 (➖ 중립)`)를 그대로 쓴다.

## 실패·예외 처리
- 메시지가 4000자를 넘으면 이슈 단위로 나눠 `(1/2)`, `(2/2)` 머리말을 붙여 보낸다.
- 발송에 실패하면 3초 뒤 1회 재시도하고, 그래도 실패하면 로그에만 기록한다.
- 콘솔에 발송 결과(성공/실패)와 메시지 길이를 출력한다.
- 결과(성공 여부, 메시지 길이, message_id, 재시도 여부, 오류)는 `logs/telegram_YYYY-MM-DD.log`(일별)와 `logs/telegram_log.json`(최근 200건)에 남긴다.
- 실패해도 종료 코드 1만 반환하고, 워크플로는 중단하지 않고 다음 단계로 진행한다.
- 참고용 문구는 절대 빼지 않는다.
